Design and generate a professional mobile application dashboard for Forest Guards called “Van Mathi”.

The app is an operational field application inspired by the workflow and map-centric design philosophy of EarthRanger, but do NOT copy its UI, branding, logo, or exact layout. Create an original modern interface optimized for forest officers working in remote forest areas.

1. PRIMARY PURPOSE

The application helps forest guards:

- Receive AI-assigned missions
- View the currently active mission
- View all previous/completed missions
- Navigate to assigned incident locations using GPS
- Work in areas with poor or no internet connectivity
- Download offline field maps and resource information
- Record field observations
- Capture photographs
- Upload captured images for Computer Vision (CV) analysis
- GPS-tag field events
- Receive locally available alerts
- Create field reports
- Synchronize collected data when connectivity is restored

The design must feel like a real forest field-operation application, not a normal admin dashboard.

16. VISUAL DESIGN

Use a professional environmental/field-operations visual language.

Design requirements:

- Mobile-first
- Clean
- Modern
- Professional
- Minimal clutter
- Large touch targets
- Easy to use outdoors
- Readable under sunlight
- High contrast
- Rounded cards
- Clear icons
- Map-centric interface
- Clear warning indicators
- Avoid excessive animations

Use a natural forest-inspired visual identity with restrained green/earth tones, but maintain strong contrast for emergency information.

Do NOT make it look like a generic banking app, e-commerce app, or normal analytics dashboard.

The interface should feel like a real mission-control tool used by forest personnel in the field.

---

17. IMPORTANT USER EXPERIENCE

The most important information on the app should always be:

1. What mission is assigned?
2. Where is it?
3. What is the risk?
4. How severe is it?
5. What should the guard do?
6. How can the guard navigate there?
7. Can the guard work without internet?
8. How can the guard capture and submit evidence?

The guard should be able to reach the active mission and navigation screen within 1–2 taps from Home.
